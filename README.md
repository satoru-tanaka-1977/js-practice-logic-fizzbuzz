# js-practice-logic-fizzbuzz

JavaScriptの条件分岐（`if`）とループ（`for`）、そして剰余演算子（`%`）を使った「FizzBuzz（世界のナベアツ的判定）」のロジック学習用アプリケーションです。

## 概要
1から100までの数字を順番に処理し、以下のルールに従って画面およびコンソールに結果を出力・表示します：
- **3の倍数**のときは **"Fizz"**
- **5の倍数**のときは **"Buzz"**
- **3と5の両方の倍数（15の倍数）**のときは **"FizzBuzz"**
- それ以外の数字はそのまま表示

プログラミングにおける「計算・条件分岐・繰り返し」というロジックの基本を学ぶための定番課題です。

## 使用技術
- HTML5 / CSS3
- JavaScript (Vanilla JS)
